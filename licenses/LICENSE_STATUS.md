# License status

This anonymous supplementary archive does not assert a new open-source license
over third-party-derived code.

The starting implementation lineage for `src/mnad/` is the public MNADrc
reimplementation (`alchemi5t/MNADrc`), not a fresh copy of the official MNAD
repository.  MNADrc itself reimplements the MNAD method and cites the official
project.  The local `MNADrc-master` snapshot used for the experiments did not
contain an explicit license file at package-freeze time.  Copyright therefore
remains with the respective authors, and the absence of a license must not be
interpreted as permission for unrestricted redistribution.

This archive may be supplied confidentially to conference reviewers for
reproducibility inspection.  Before creating a permanent public repository,
the authors must either obtain permission, replace the derived files with a
patch against an authorized upstream distribution, or adopt another legally
valid release route.  Original additions in `src/decision/`, `scripts/`, and
`tests/` can be licensed separately once the upstream boundary is resolved.
